## 非阻断警告与未覆盖项

1. Starlette 的 TestClient 对 httpx 给出弃用提示；所有相关测试通过，后续依赖升级时迁移客户端。
2. Vite 提示主 JS bundle 超过 500 kB，主要包含 PDF.js；后续阶段按需拆包，不影响当前构建/测试。
3. 解析 confidence 是保守启发式值，不是校准后的识别准确率；未完成通用复杂版面评估。
4. 旋转页几何与渲染已测试，文字阅读顺序仍需复核；CropBox 差异时关闭覆盖层，非标准坐标原点待扩展回归。
5. 无图表结构恢复、扫描 OCR、可信公式识别，也无 UI 人工校正编辑器；不返回虚构 LaTeX。
6. 第三方模型列表、认证、协议、真实翻译与费用均未测试。本轮没有 Key、论文内容或其他数据外传。
7. API 仅为本机单用户开发服务，无认证和公网部署防护，不可开放到外网。
8. 阶段 0 CLI 有输入文件大小/页数限制，但没有任务隔离和资源配额，不可直接当作面向用户的上传处理器。
