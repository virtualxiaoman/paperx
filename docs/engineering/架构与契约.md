# 阶段 0：架构与数据契约

日期：2026-10-01。以原任务文档为产品范围，本文件只固化已验证的工程边界。

## 选型

- Python FastAPI + Pydantic；React + TypeScript + PDF.js。精确版本见锁文件。
- 候选对比：pdfplumber 提取带字体/位置的词，用于空间结构原型；pypdf 提取整页文本作为基线，不作为当前坐标块实现。
- 对比脚本在同一输入上运行两者，结果在 `data/parser-comparison.json`。这是耗时/覆盖和重复性观测，不是通用准确率排名。
- PDF 文本中的数学字形不能当作 LaTeX；合成公式 3/3 被识别为候选，但 0/3 具备可复制 LaTeX。真实论文也存在丢字、错序和 CID 替代字符。
- 当前不引入重量级公式 OCR/视觉模型，避免把未经验证识别能力接入 P0。后续经 FormulaProvider 插拔，对人工真值验证后才启用。
- Worker、SQLite、翻译、向量数据库都未实现，本轮没有伪造任务成功结果。

## 契约文件

`document.schema.json`、`task.schema.json`、`openapi.json` 由项目内 Python 生成。源定义位于 `backend/paperx/models.py`。

- Sample.id 是验证样本路由别名；Sample.paper.id 与 Document.paper_id 一致，避免把演示路由当作论文实体 ID。
- Page 从 1 起；Block.order 从 0 起且连续；Block.id 在相同 PDF 字节和 parser_version 下稳定。
- ID 使用 PDF SHA-256、解析器/算法版本、页码、顺序、bbox、文本的组合哈希；不来自浏览器 DOM。
- parser_version 包含 pdfplumber 版本。锁文件中的 PDFMiner 更新也可能改变结果，更新依赖必须同时递增算法版本。
- 重解析不得覆盖旧版本；Document 预留 previous_parser_version / previous_id_map，阶段 1 才实现实际迁移与持久化。
- bbox 为未旋转 **MediaBox** 中归一化的左上角 x/y/width/height；不是像素，也不是左下原点。
- page.width/height 是未旋转的 PDF 点数；rotation 为顺时针 0/90/180/270。
- PDF.js 默认使用 CropBox：验证器检测尺寸差异，发现裁剪时关闭覆盖层，避免给出虚假定位。偏移非零但尺寸相同的异常 CropBox 仍需扩展回归。
- Location 数组允许跨页/不连续区域；本轮解析器输出单矩形。
- Section 为树，block_id 必须存在。TranslationBlock 支持一对多 source_block_ids；未知映射必须明确 unmapped。
- Formula 保存 latex / source / confidence / status / revision / verified_by；verified 必须有非空 LaTeX 与审核来源。置信度高本身不能解除复制限制。
- Task 契约：queued/running/succeeded/failed/cancelled，stage/progress/retries/error。尚无任务端点。

## 当前 API（只读）

- GET /health
- GET /samples
- GET /samples/{id}/document
- GET /samples/{id}/pdf：支持 Range，服务器返回原 PDF。

这些是可行性验证接口，**不冒充已完成 /papers 业务接口**。任务书中的 /papers、/tasks、/settings、/search 将随相应阶段固化，不能先发布空实现。

应用层错误：`{"error":{"code":"NOT_FOUND","message":"...","retryable":false}}`。
所有应用路由的验证错误/404/405/500统一该结构。底层文件传输 Range 错误由 Starlette 处理，416 保留 HTTP 内容范围语义；响应体不承诺应用 JSON。

## 安全边界

- 默认只监听 127.0.0.1；无通配 CORS；Vite 同源代理。单用户开发工具，无身份认证，不可暴露到公网。
- 前端不接触 Provider、模型名称或 API Key。当前服务无网络下载和 AI 请求能力。
- 样本接口仅接受受限 ID，不接受任意文件路径；只读取准备脚本生成的数据目录。
- 原始 paper/、data/、.env、.venv、构建与浏览器报告已忽略；合成测试 PDF 可提交。
- 后续上传与 arXiv 必须落实限流/限大小/超时/目标白名单、SSRF 防护、任务隔离和原子落盘，不能复用本轮同步 CLI 当作生产任务队列。
- 默认模型保留用户指定 gpt-5.6-terra，不自动替换其他模型。第三方服务协议、模型列表、费率尚未验证。

## 降级与不确定性

confidence 为启发式估计，不是经校准的概率。多栏仅检测明显中缝，不保证所有版式；标题依赖字体/编号启发式。旋转页保存正确坐标约定，但文本阅读顺序仍需要复核。扫描页不返回虚构文本。图、表仍只有可提取文字，尚未恢复结构。公式候选可能漏检，也可能把含等号的正文误判为公式。

人工校正路线：保留原块和 bbox → 展示原文区域 → 用户填写/校正 LaTeX → 渲染检查 → 保存 revision 与 verified_by → 允许复制。该路线已写入数据约束，完整交互和版本存储在后续阶段实现。
